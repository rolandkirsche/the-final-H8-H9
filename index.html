Bedienung (echtes PAM-8-ROM)

MEM (#) drücken, dann 6 Oktalziffern eingeben (z. B. 0 4 0 1 0 0) — die Anzeige zeigt Adresse und Speicherinhalt. Mit +/− vor- und zurückblättern.

ALTER (/) schaltet den Änderungsmodus ein: im MEM-Modus schreiben je 3 Oktalziffern ein Byte und schalten zur nächsten Adresse weiter; im REG-Modus überschreiben 6 Oktalziffern das gewählte Registerpaar. Nochmal ALTER beendet.

REG (·) und dann 1–6 zeigt ein Registerpaar: 1=SP, 2=AF, 3=BC, 4=DE, 5=HL, 6=PC.

GO (4) startet ab PC — dafür vorher REG→6→ALTER→Startadresse (6 Ziffern)→ALTER, das bloße Anzeigen einer Adresse über MEM reicht nicht. SI (7) führt einen Einzelschritt aus. Umschalt-Klick auf 0 (bzw. Umschalt+0) löst RTM aus, Strg-Klick auf 0 (bzw. Strg+0) löst RESET aus.

Die drei Demo-Knöpfe (Demoprogramm, Hello World, Zeilen-Umkehr) schreiben ihr Programm direkt in den RAM und setzen PC automatisch auf den Programmanfang — danach nur noch GO drücken.

Konsole: echte H8-5 Serial I/O Card (Intel-8251-USART) an Port 372₈/373₈ — Benton Harbor BASIC laden legt das virtuelle Kassettenband ein und lädt über PAM-8s eingebauten LOAD-Befehl (Port 370₈/371₈). Die beiden eigenen Demos (Hello World, Zeilen-Umkehr) nutzen daneben weiterhin ein eigenes, einfacheres UART-Modell an Port 350₈/355₈.

H9-Bildschirmtasten (unter dem Terminal): HOME setzt den Cursor an den Anfang, die Pfeiltasten bewegen ihn, EOL löscht ab Cursor bis Zeilenende, PAGE ab Cursor bis Bildschirmende, ERASE löscht den ganzen Bildschirm. Das sind reine Bildschirmfunktionen direkt auf dem H9-Puffer — sie senden nichts an die H8-Seite und stören daher eine laufende BASIC-Sitzung nicht, wirken aber sofort auf das als Nächstes Angezeigte.

Kassettendeck (rechts neben dem H8): über das Auswahlfeld ein Band einlegen (leer oder Benton Harbor BASIC) oder eine eigene Banddatei laden. LOAD (8) liest danach ganz normal über PAM-8s Kassettenroutine, DUMP (9) schreibt (Start-/Endadresse wie gewohnt am Panel eingeben) — beides läuft über den echten ROM-Code, die UI legt nur das Band ein. Schreibgeschützte Bänder (z. B. BASIC) lassen sich per Häkchen entsperren. „Rücklauf" setzt die Bandposition zurück auf Anfang, „Band speichern …" lädt das aktuelle Band als Datei herunter.

Acey Ducey laden lädt bei Bedarf zuerst Benton Harbor BASIC und tippt danach das Original-BASIC-Spiel "Acey Ducey" (Creative Computing, 1978) automatisch Zeichen für Zeichen in die laufende Sitzung — genau wie ein echter Tastatureingang, inklusive der Auto-Abkürzung unten. Danach RUN eintippen zum Spielen.

BASIC-Eingabe: Schlüsselwörter werden beim Tippen automatisch zur kürzesten eindeutigen Abkürzung ergänzt (PR → PRINT , RU → RUN ) — original 1977er-Verhalten zum Tastensparen. Wer ein Schlüsselwort trotzdem ganz ausschreibt, tippt nach der Auto-Ergänzung ungewollt weiter in ein neues Token hinein (z. B. wird aus PRINT so PRINT INT(). Abkürzungen verwenden oder das Wort direkt nach der Auto-Ergänzung stehen lassen.

Läuft mit dem originalen PAM-8-Monitor-ROM (Heath 444-13, J.G. Letwin, 1976) und dem originalen Benton-Harbor-BASIC-Kassettenband (Heath/Wintek, Issue 05.01.01, 1977, SEBHC-Software-Archiv) — kein Nachbau. Tastenmatrix, Frontpanel-Port-Protokoll (360₈/361₈), Zeichentabellen und das H8-5-Konsolprotokoll gegen die laufende Original-Firmware sowie den Quelltext „XCON8 ROM.asm" (T. Gulczynski Re-Creation, 2009) verifiziert, portiert aus dem Schwesterprojekt virtual-h8-h9. LOAD und DUMP sprechen beide dieselbe virtuelle Bandschnittstelle über Port 370₈/371₈ an; ohne eingelegtes Band wartet LOAD wie am Original (abbrechbar mit CANCEL) und DUMP schreibt ins Leere.
Echter Intel-8080A-Softwarekern mit 64 KB RAM; der Bereich 000.000–001777 oktal ist als Original-PAM-8-ROM schreibgeschützt. Das H9 stellt hier 12 Zeilen à 80 Zeichen dar (Original) und zeigt nur Großbuchstaben; mit ?rows=24 in der Adresse läuft der historische 24-Zeilen-Ausbau.
